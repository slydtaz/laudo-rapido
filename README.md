# LaudoRápido

Primeira startup do diretório `STARTUPS`.

**O que é:** aplicativo para técnicos de campo registrarem uma visita (fotos antes/depois, observações, assinatura do cliente) e saírem com um PDF formal entregue na hora — funcionando mesmo sem internet.

**O que NÃO é:** um bloco de notas de lembretes. É documentação de entrega, com valor jurídico e operacional para o cliente.
